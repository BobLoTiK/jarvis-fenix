- [2026-10-26 00:12] [经验教训] `-X utf8` для subprocess с `-I`; errors="replace" — не фикс кодировки — Фикс красного check_all на кириллическом имени пользователя: в tests/test_bootstrap_ollama_config.py дочернему процессу нужен ФЛАГ КОМАНДНОЙ СТРОКИ `-X utf8` (`python -X utf8 -I -c ...`) плюс encoding="utf-8" у check_output. Причина: `-I` изолирует процесс и игнорирует PYTHONUTF8/PYTHONIOENCODING, поэтому print уходит в кодировку консоли (cp1251), а родитель декодирует UTF-8. ВАЖНЫЙ ОТРИЦАТЕЛЬНЫЙ РЕЗУЛЬТАТ: `errors="replace"` НЕ является фиксом — тест перестаёт падать с UnicodeDecodeError, но получает битый путь 'C:\\Users\\?????' и валится с PermissionError [WinError 5]. Не применять как «лечение» кодировки.
Там же осталось неизменным: PYTHONUTF8=1 в check_all.py:37 сам по себе корректен, ломать его не надо.
