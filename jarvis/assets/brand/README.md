# Фирменные ресурсы Феникса

Птица — самостоятельная векторная перерисовка выбранного пользователем
AI-концепта 01: сохранены три пера с каждой стороны, голова и длинный
изогнутый хвост. Геометрия одинакова в обеих темах и во всех размерах;
меняется только контрастная палитра. Дополнительные пиктограммы — единый контурный набор 24×24, толщина линий
1.8 единицы. Небольшие смысловые детали: строки диалога, решётка микрофона,
воротник персоны, заголовок окна команд и деления таймера. Без искр и завитков.
Это не фрагменты сравнительной картинки и не сторонний набор значков.
SVG — редактируемый исходник; PNG — производные для Flet (без SVG runtime).
Тёмный и светлый варианты имеют прозрачный фон. icon.ico и tray.png
собираются `python scripts/make_icon.py` из phoenix-dark.png через Pillow,
который уже используется проектом. Исходные SVG сохранять вместе с PNG.
