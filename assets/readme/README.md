# Графика README

- `hero.svg`, `hero-mobile.svg` — фирменная обложка с птицей Феникса.
- `commands.svg`, `commands-mobile.svg` — три примера реальных команд.
- `themes.svg`, `themes-mobile.svg` — образцы палитр Сумерки / Фарфор.

Это редакционные иллюстрации, не скриншоты и не макеты окон приложения.
Цвета тем взяты из `jarvis/gui.py`, геометрия птицы и значков — из
`jarvis/assets/brand/`. Без новых логотипов, выдуманных результатов и статусов.

Внешних шрифтов, сетевых ресурсов, скриптов и анимации внутри SVG нет.
Основной текст, инструкции и ссылки остаются в Markdown. Для узких экранов
используются отдельные композиции; alt-текст сохраняет смысл примеров.

После правки проверять широкие и мобильные варианты, светлую/тёмную страницу
и раскрытые инструкции. Имена SVG включены явным списком в curated payload,
чтобы картинки не потерялись рядом с установленным README.
