# Обложки README

- `hero.svg` — широкая обложка для страницы репозитория.
- `hero-mobile.svg` — компактная композиция для узкого экрана.

Графитовый фон и медный акцент соответствуют интерфейсу Феникса.
Геометрия птицы взята из `jarvis/assets/brand/phoenix-dark.svg` без изменения
фирменного знака. Это редактируемые векторные обложки, не скриншоты приложения.
Внешних шрифтов, скриптов, анимации и сетевых ресурсов внутри SVG нет.

При замене проверять обе композиции. Названия файлов сохранять: на них ссылается
README и curated installer payload. Не добавлять в обложку обещания скорости,
результаты тестов или статус релиза — они быстро устаревают.
