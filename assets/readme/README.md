# Графика README

- `hero.svg`, `hero-mobile.svg` — фирменная обложка с птицей Феникса.
- `commands.svg`, `commands-mobile.svg` — три примера реальных команд.
- `themes.svg`, `themes-mobile.svg` — образцы палитр Сумерки / Фарфор.
- `screen-home.png`, `screen-palette.png`, `screen-dialog.png`, `screen-strip.png` —
  **реальные снимки окна** текущей сборки (тема «Фарфор», полоса — «Сумерки»),
  снятые через PrintWindow. Это не макеты: на них видно настоящее состояние
  статус-бара, включая честное «Ядро ещё не готово».

SVG — редакционные иллюстрации, не скриншоты и не макеты окон приложения.
Цвета тем взяты из `jarvis/gui.py`, геометрия птицы и значков — из
`jarvis/assets/brand/`. Без новых логотипов, выдуманных результатов и статусов.

Внешних шрифтов, сетевых ресурсов, скриптов и анимации внутри SVG нет.
Основной текст, инструкции и ссылки остаются в Markdown. Для узких экранов
используются отдельные композиции; alt-текст сохраняет смысл примеров.

PNG-скриншоты снимаются вручную живым прогоном приложения; папка попадает в
выпускаемый payload, поэтому PNG добавлены явным списком рядом с SVG — иначе
картинки рядом с установленным README потеряются.

После правки проверять широкие и мобильные варианты, светлую/тёмную страницу
и раскрытые инструкции. Имена SVG и PNG включены явным списком в curated payload.
