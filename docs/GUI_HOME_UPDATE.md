# Минималистичная Главная — обновление проекта

## Установка

1. Полностью закрой Феникс, включая значок в трее.
2. Сделай резервную копию. Распакуй ZIP в корень проекта (рядом с main.py)
   с заменой файлов. Зависимости переустанавливать не нужно.
3. Запусти привычным способом. Если включён запуск только в трее:
   правой кнопкой по значку → «Открыть окно».

В архиве нет рабочего config.json, профилей, истории и .venv.
config.example.json — только пример, не подмена пользовательского конфига.

## Что изменилось

При запуске GUI открывается Главная: птица по центру, небольшие дата/время,
подпись состояния и две кнопки общей темы. Поля сообщений и карточек на ней нет.
Переписка доступна в отдельном втором пункте «Диалог».
Виджеты, планировщик и новая интерактивка в центре пока не переносились.
Кнопка/фальшивый редактор будущих виджетов не добавлены.

## Проверить на Windows

- [ ] При запуске и после «Открыть окно» из трея Главная отображается правильно.
      Повторное открытие существующего окна сохраняет выбранную вкладку.
- [ ] На Главной нет сообщений, поля ввода, карточек задач и фиктивных виджетов.
- [ ] Открой «Диалог», введи черновик, вернись на Главную и обратно: текст остаётся.
- [ ] Переключи Сумерки/Фарфор на Главной: общий фон/птица/панель меняются,
      черновик и переписка сохраняются. Проверь обычную смену темы в Настройках.
- [ ] Пройди все семь пунктов, включая «Мои команды». В 900×600 список
      прокручивается; булавка и профиль остаются доступны. Проверь DPI 100/125/150%.
- [ ] Наведи на панель на широком и узком окне: контент плавно уступает место
      в обоих случаях, без перекрытия. Закрепление и сохранение после перезапуска работают.
- [ ] «Микрофон»/«Настройки» из трея открывают правильные разделы.
- [ ] Дата/время соответствуют системным; оставь Главную на смене минуты.
      Уход на другую вкладку/закрытие не вызывает ошибок часов.
- [ ] Запусти голосовую команду, оставаясь на Главной: статус отражает обработку,
      а переписка находится в «Диалоге», без автоматического переключения вкладки.

Солнечная корона и отключение предупреждения добавлены следующим пакетом:
`GUI_SOLAR_AURA_UPDATE.md`.

## Границы проверки

Автотесты и рендер настоящего Flet-клиента выполнены на Linux, не Windows.
Они не подтверждают реальное TTS, физический микрофон, системный трей и DPI.
Главная не запускает ИИ/микрофон сама и не показывает выдуманную доступность модели.
