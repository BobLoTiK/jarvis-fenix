# Виджеты Главной: первый набор

## Установка
Полностью закрой Феникс, включая трей. Сделай резервную копию проекта.
Распакуй обновление в корень проекта рядом с launcher.py, сохранив папки
и заменив файлы. Запусти обычным способом. Новые зависимости не нужны.
Архив не содержит твоих config.json, tasks.json, профилей, истории, моделей
или .venv. Это исходное обновление, не пересобранный установщик/EXE.

## Что появилось
По умолчанию Главная по-прежнему минимальна: аура, дата, время, статус.
Нажми «+ Виджеты» внизу справа и выбери карточки:

- **Задачи**: добавить текст и нажать Enter/плюс; отметить или снять отметку.
  Это тот же локальный список, что у голосовых команд, а не отдельная копия.
  Хранилище задач общее для пользователя Windows, не для каждого профиля.
  Совпадающие названия безопасны: отметка меняет точный ID.
- **Быстрые действия**: до шести собственных названий и команд Фениксу.
  Добавление не запускает команду. После сохранения только явное нажатие
  открывает Диалог и проходит обычный обработчик команд, блокировки и
  подтверждения. Нет прямого shell/exec. Если ядро не готово, занято или
  ждёт ответа/пароля, действие не отправляется повторно в обход этого шага.

В настройке можно менять ширину карточки (компактная/широкая), переставлять
стрелками или перетаскиванием за точечную ручку, убирать крестиком.
Это упорядоченная адаптивная сетка под аурой, не свободные координаты по экрану.
На узком окне карточки становятся друг под другом. При нехватке высоты
прокручивается рабочая область; меню и «+ Виджеты» остаются снаружи неё.
Сдвиг содержимого при раскрытии бокового меню сохранён на любой ширине.

«Сохранить» атомарно записывает раскладку и быстрые команды в config.json;
«Отмена» возвращает сохранённое. При конфликте/ошибке записи черновик остаётся.
Смена темы не теряет открытый черновик редактора и текст новой задачи.
Убрать карточку — не удалить её задачи/команды. Добавление/отметка задач
сохраняется сразу, независимо от редактора раскладки. Удаления задач в этом
виджете пока нет: остаются существующие голосовые команды.
При большом списке отображаются первые 100 задач (незавершённые первыми).

## Нагрузка
Нет нового потока, аудиозахвата или отдельного таймера обновления.
Используется существующий секундный тик Главной: проверка размера/mtime
файла задач и чтение только при изменении. В пустой Главной задачи не читаются.
Аура и кольцо действий используют прежний lifecycle; облака не добавлялись.

## Что проверить на Windows
1. Первый запуск без карточек → «Виджеты» → добавить обе → «Сохранить».
2. Добавить две задачи с одинаковым названием, отметить одну и снять отметку.
   Добавить голосом ещё одну: карточка должна обновиться без потери ввода.
3. Добавить действие «Время» / «который час». В редакторе оно не запускается;
   после сохранения нажатие открывает Диалог с обычной обработкой команды.
4. Перетащить в обоих направлениях; проверить стрелки, ширину, «Отмена».
5. Сменить тему с незавершённым вводом, пройти на другую вкладку и обратно.
6. Убрать карточку и вернуть: данные остаются. Перезапустить: раскладка остаётся.
7. Узкое окно и обе темы; боковая панель отодвигает контент, не закрывает его.
8. Повторить кольцо: микрофон, стоп речи и Диалог, затем скрытие в трей/возврат.

Проверки стенда: unit/lifecycle tests на Flet 1.0.3/1.0.4, реальный Flet web-render.
Это не замена приёмки Windows/DPI, физического аудио и системного трея.
