# Исправления после проверки архива

## Что изменено

- Напоминания не подтверждаются и не планируются при ошибке записи.
  Неудачная отмена не останавливает действующие таймеры. Ошибка удаления
  уже сработавшего напоминания не заглушает его уведомление; она записывается
  в лог с предупреждением о возможном повторе после перезапуска.
- Удаление задач понимает обе формы: «убери хлеб из списка» и
  «убери из списка хлеб». При отсутствии названия запрашивается уточнение.
- Готовность Vosk проверяется по обязательным непустым файлам, а не по папке
  `am`. Загрузка и копирование выполняются во временную папку; конечный
  каталог заменяется только после проверки.
- ZIP-элементы с выходом за папку модели, абсолютными путями, Windows-дисками,
  альтернативными потоками, точкой/пробелом на конце компонента пути и
  символическими ссылками отклоняются.
- Лаунчер и приложение используют один проверяющий и устанавливающий код
  Vosk и одинаковый выбор ASCII-пути.
- Добавлены регрессионные тесты и обновлён `SNAPSHOT.md`.

## Применение архива с заменами

Закрой Феникс. Распакуй архив с заменами **в корень существующего проекта**:
это папка, где находится `launcher.py`. Подтверди замену файлов. Архив
содержит только исправленные исходники, новые тесты, этот документ и снимок.
Он не заменяет виртуальное окружение, модели или пользовательские настройки.

Если используешь полный архив исходников, распакуй его отдельно. В нём нет
`.venv311`, истории Git, `build`, `dist`, кэшей, старых журналов и ранее
скомпилированных EXE. Модели и ресурсы из исходного архива сохранены.

## Запуск на Windows

Старый `Феникс.exe` не пересобран: изменения самого лаунчера в него
не встроены. Используй исправленный `launcher.py`:

```bat
.\.venv311\Scripts\python.exe launcher.py
```

Для новой распаковки без окружения:

```bat
py -3.11 -m venv .venv311
.\.venv311\Scripts\python.exe -m pip install --upgrade pip
.\.venv311\Scripts\python.exe -m pip install -r requirements.txt
.\.venv311\Scripts\python.exe launcher.py
```

Окружение из старого архива содержит абсолютный путь к Python исходного
компьютера. Если оно не запускается на другом ПК, переименуй его и создай
заново. Настройки и профили удалять не нужно.

## Проверки

Новые тесты не используют сеть, микрофон и системную автоматизацию:

```bat
.\.venv311\Scripts\python.exe -m pytest tests/test_review_regressions.py -q
.\.venv311\Scripts\python.exe -m pytest tests/ -q
.\.venv311\Scripts\python.exe snapshot.py --check
.\.venv311\Scripts\python.exe scripts/build_setup.py --check
```

Проверка исправлений выполнена на Linux. Нативная работа на Windows,
реальные микрофон/TTS/UIA, сборка EXE и установщика требуют отдельного
Windows-прогона. Не считай эти проверки выполненными только по результату
модульных тестов.
