# Исправление старта окна и трея

## Установка

1. Полностью выйди из Феникса, включая работающий фоновый процесс/трей.
2. Сделай резервную копию проекта.
3. Распакуй архив в корень проекта с заменой файлов, затем запусти заново.

В архиве нет config.json, профилей, истории, .venv, моделей или нового EXE.
Это накопительное обновление: минимальная Главная, плавная аура, сдвиг
контента при наведении и предыдущее отключение озвучки тишины сохранены.
launcher.py — исходник для будущей сборки; существующий Феникс.exe можно
оставить: основной процесс поддерживает его старую схему блокировки.

## Что изменено

- До первого показа native-клиент Flet скрыт. Название «Феникс», ICO и
  интерфейс отправляются до команды показа окна. Обычный GUI-режим явно
  выставляет visible=True и minimized=False; tray-режим не показывает окно.
- Проверяется готовность трея до решения о скрытом старте. На Windows
  проверяется результат Shell_NotifyIconW с короткими повторами, а не только
  оптимистичный флаг pystray. Если создание не удалось, окно остаётся доступным.
- Если активный message loop трея упал, окно восстанавливается через GUI-очередь.
- Устранена гонка общего mutex у старого launcher/ядра; HANDLE корректен на Win64.
  Повторный настоящий экземпляр по-прежнему не запускается (проверка до 3 с).
- Изменение режима закрытия окна больше не трогает Flet из фонового потока.

## Что проверить на своём ПК

1. **Обычный запуск:** Настройки → «Запуск и окно» → «При запуске приложения» →
   «Показывать окно», «Оставаться в трее» включено → «Применить изменения».
   Полностью выйди и запусти 5–10 раз, в том числе через привычный EXE/ярлык.
   Окно должно появляться; перед ним не должно мелькать название/иконка Flet.
2. **Значок:** найди Феникса у часов И под стрелкой «^» скрытых значков.
   Нажми крестик окна → «Открыть окно» в контекстном меню значка. Окно возвращается.
   Windows сама выбирает скрытые значки: можно перетащить Феникса оттуда к часам.
3. **Только трей:** выбери этот режим, сохрани, полностью перезапусти.
   Окно не появляется до «Открыть окно»; значок должен быть доступен.
4. **Без трея:** выключи «Оставаться в трее», оставь «Показывать окно», сохрани.
   После перезапуска окно видно, а крестик завершает GUI, не прячет его.
5. **Регрессии:** hover-панель отодвигает содержимое, обе темы и плавная аура работают.

Если значка по-прежнему нет даже под «^», пришли журнал запуска из logs/
(учти, что журнал может содержать фразы диалога — личное можно удалить).
Отсутствующая pystray/Pillow или отказ Windows записываются в лог; переустановка
всего проекта без диагностики не нужна.

## Проверено на стенде

Автотесты: скрытый клиент, порядок branding/layout/show, GUI/tray intent,
потокобезопасный prevent_close, mutex-handoff, отказ Shell_NotifyIcon,
готовность/таймаут/падение message loop, восстановление окна, устаревшие callbacks.
Используется dummy-backend для pystray, не настоящий Windows Explorer.
Настоящие Windows-значок, старый скомпилированный EXE, стартовый кадр/DPI и
звук требуют ручной проверки на Windows. Новых зависимостей не добавлено.
