# Феникс 2.1.1

Патч поверх 2.1.0. Тег `v2.1.0` не перемещался.

## Главное

- **Необратимые действия больше не выполняются без пароля.** При пустом `danger_password`
  ранее `is_danger()` возвращал False, и выключение ПК, перезагрузка, убийство процесса и
  удаление профиля проходили как обычные команды. Теперь опасность действия не зависит от
  того, задан ли пароль: всё решает единая точка `danger_gate()`.
- **«Удали профиль Максим» больше не стирает активный профиль.** Guard сравнивал сырое имя
  пользователя с именем папки и на кириллице с заглавной буквой не срабатывал никогда.
- Надёжность первого запуска Windows: проверка VC++ x64, HTTPS-загрузка Python через
  системный PowerShell с двойной проверкой Authenticode, отказ необязательного Whisper
  не блокирует старт на Vosk.
- Подготовка Python и модели Ollama в одном окне: явный выбор модели, загрузка только
  выбранной, наличие проверяется без inference.
- README перестроен, добавлены обложки и образцы палитр; поставка остаётся курируемой.

## Безопасность: действия и профили

- `profile.delete()` сравнивает имена папок профилей (`_sanitize(current())`), а не сырое
  имя пользователя. Доказано репро в temp-папке: до фикса удалялся активный профиль.
- `is_danger()` больше не зависит от `danger_password`; пароль отвечает на вопрос «можно ли
  выполнить», а не «опасно ли это».
- Единый гейт `danger_gate()`: пароль задан → спрашиваем; пароля нет и действие необратимо →
  безопасный отказ; отменяемое (`clear_tasks`, `cancel_timers`) → как раньше.
- Гейт подключён в LLM-стадии, кастомных и пак-командах и в «удали профиль X». Строковая
  пак-команда вида `open_app` + `shutdown /r /t 10` тоже под гейтом.
- Порядок стадий и ожидание pending-пароля не менялись; ошибка не выдаётся за успех.

## Надёжность и поставка

- VC++ x64: проверка системных DLL, явное согласие, официальный HTTPS-download, Valid
  Authenticode «Microsoft Corporation» дважды, интерактивный установщик и recheck.
- Штатные сообщения подготовки — одно графитово-медное окно Tk без Flet: progress загрузок,
  индикатор pip, inline-вопросы, ошибка/повтор/журнал. Отказ возможен только до начала этапа.
- Process-local certifi для `-m jarvis`; приватные CA не подменяются, TLS/hostname
  verification не отключается.
- Неудачный запуск приложения/браузера/Steam не маскируется успехом; Whisper при отказе CUDA
  делает одну попытку CPU int8 той же модели без нового download.
- Курируемый payload получил проверку состава и SHA-256 manifest, без конфигов, истории,
  моделей и диагностики сборщика.

## Установка и обновление

Используйте `Феникс_Setup.exe`. Отдельный `Феникс.exe` — bootstrap-лаунчер, а не автономный
пакет с Python и моделями: первый запуск требует интернета, модели загружаются отдельно.

Перед обновлением полностью завершите Феникса через меню трея и ставьте в прежнюю папку.
Пользовательские данные и модели не входят в payload и не сбрасываются. Если requirements
изменился, лаунчер предложит обновить зависимости.

Оба файла **не подписаны** (Authenticode: NotSigned) — SmartScreen покажет предупреждение.
