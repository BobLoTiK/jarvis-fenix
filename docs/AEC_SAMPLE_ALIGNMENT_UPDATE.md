# AEC: точность сравнения с воспроизводимым голосом

## Что исправлено

1. Сравнение PCM с голосом Piper больше не перебирает задержку с шагом
   20 мс. Такой шаг пропускал корреляцию, если фактическая задержка попадала
   между точками сетки. Теперь нормированная взаимная корреляция проверяет
   каждый отсчёт в прежнем диапазоне −100…500 мс: при 16 кГц это 0,0625 мс.
   Для двух сигналов (микрофон и очищенный PCM) используется общий render FFT.
2. Коэффициент подавления рассчитывается для каждого текущего блока, в том
   числе тихого. Раньше при RMS микрофона ниже 150 мог передаваться коэффициент
   от предыдущего блока. При отсутствии измеримого входа значение — None,
   а не сохранённое старое число.
3. Единый преобразователь временных меток в PCM для AEC и корреляции учитывает
   погрешность float на стыках блоков. Неизвестные участки истории не считаются
   валидным эталоном; постоянный DC-сигнал не считается совпадением голоса.
4. Сообщение `Barge-in AEC: стоп` переименовано в `завершение контроля`:
   обычный конец озвучки не должен выглядеть как ложное прерывание.
   `reason=triggered` и отдельное сообщение о срабатывании остаются.

Пороги VAD, RMS, корреляции, длительность подтверждения (320 мс), native AEC3,
NS/AGC, управление воспроизведением и предзапись начала реплики не изменены.
Новых зависимостей, конфигурационных ключей и обходных аудиотрактов нет.

## Установка поверх предыдущего обновления AEC

1. Полностью закрыть Феникс.
2. Распаковать архив в `C:\jarvis` с заменой файлов, сохранив структуру папок.
3. Запустить обычным `start_fenix.bat` или своей командой `fenix`.

Повторный запуск `install_aec.bat` не требуется, если native AEC уже установлен
и в логе есть `WebRTC AEC3 готов`. Конфигурация и модели не заменяются.

## Проверки и границы

- Тесты воспроизводят пропуск корреляции на старой сетке задержек и устаревший
  коэффициент тихого блока на прежнем коде, а затем проверяют исправленный.
- Есть синтетические проверки задержек между точками старой сетки,
  ресемплинга 22,05/48 кГц, непрерывности стыков, неполной истории, DC,
  остаточного многолучевого эха и независимой одновременной речи.
- Проверяется и обработка синтетического эха реальным native AEC3 без устройств.
- Синтетическая независимая речь не заменяет запись живого пользователя.
  Совпадение с конкретными буквами по одному логу не установлено.
- Windows, реальный микрофон, колонки, нелинейные искажения и длинная
  реверберация требуют отдельной проверки. Полное устранение самоперебивания
  в реальной комнате этим тестированием не доказано.

## Проверка на Windows

При неизменной громкости дать Фениксу несколько длинных ответов, сначала
молчать, затем перебить своим голосом. Повторить на обычном расстоянии и
вблизи колонок. Проверять не только отсутствие самоперебивания, но и то,
что собственная речь пользователя по-прежнему останавливает озвучку.
При сбое сохранить фрагмент лога с `trigger=...` и указать, говорил ли
пользователь в этот момент. Аудио автоматически не записывается.
