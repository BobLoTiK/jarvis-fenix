# Исходные требования

Документы предоставлены пользователем для разработки Феникса. Копии сохранены
без изменений, чтобы план можно было продолжить без истории чата.

- [Целевое видение JASTIN v1.1.6.0](J-A-S-T-i-n_v1_1_6_0.docx) — видение
  работодателя, к которому должен стремиться Феникс.
- [План интеграции](Phoenix_JASTIN_Integration_Plan.1.docx) — предложенный маршрут;
  различать целевое и уже существующее в коде.
- [Руководство Uvoxus 2.3b](Руководство_по_разработке_плагинов_v23b.docx) — образец
  SDK; степень совместимости будущего Phoenix API требует согласования.

[Матрица требований и оговорки](../PHOENIX_JASTIN_RECONCILIATION.md).
Версии/производительность/лицензии из исходных документов не являются нашей
проверкой. Документы включены в комплект разработки; в ZIP обновления приложения
DOCX намеренно не включены. Их отсутствие не мешает запуску и snapshot --check.
Оригиналы в этом разделе доступны при наличии комплекта разработки.
Документы не добавлены в installer
payload и не являются обещанием готовых функций. Не публиковать их от имени
авторов или под MIT проекта без отдельной проверки прав на распространение.
