# Кольцо действий Главной

## Установка

Полностью выйди из Феникса, включая трей. Сделай резервную копию проекта.
Распакуй накопительный архив в корень проекта с заменой файлов и запусти снова.
Личные config.json/профили/история/.venv/модели не включены и не заменяются.
Новых зависимостей и нового EXE нет; исправления старта/трея сохранены.

## Действия

- Наведение на птицу, Tab-focus или Enter/Space открывает кольцо.
- Сверху — открыть Диалог (ничего не отправляется в чат).
- Слева — включить/выключить существующий микрофон ассистента.
- Справа — остановить текущую озвучку. Без речи кнопка приглушена и недоступна.
- Под кольцом появляется название выбранного действия. Без стандартных белых
  tooltip-плашек; у кнопок есть семантические названия для screen reader.
- Уход из общей зоны закрывает кольцо через 240 мс; сами переходы — 220 мс.
  При перемещении от птицы к кнопкам кольцо не схлопывается.
- Escape закрывает и возвращает фокус птице; Tab переносит его по действиям.
- При отключённых анимациях/OS reduced motion переходы мгновенные.

Нет ядра — микрофон и stop недоступны, Диалог всё равно можно открыть.
Stop прекращает озвучку, но не отменяет выполненную команду/генерацию.
Главная осталась минимальной; виджеты и Планы в этом пакете не добавлены.

## Что проверить

1. Наведи на птицу, медленно дойди до каждой кнопки: кольцо не исчезает.
   Уведи курсор за него — оно закрывается без изменения компоновки.
2. Микрофон выключается/включается по левой кнопке, меняются значок, подпись
   и фактический приём команд (проверить с настоящим микрофоном на Windows).
3. Во время озвучки нажми правую кнопку: речь останавливается, без озвучки
   кнопка недоступна. Никакие завершённые действия не откатываются.
4. Верхняя кнопка открывает Диалог отдельно, без отправки пустого сообщения.
5. Tab до птицы → Tab по действиям → Escape; затем повторное открытие.
6. Обе темы, отключённые анимации, переходы между вкладками и скрытие в трей.
   После возврата с другой вкладки меню закрыто, прежняя аура работает.
7. Боковая панель по наведению по-прежнему отодвигает содержимое.

## Проверка на стенде

Flet 1.0.3 и 1.0.4, unit/lifecycle tests, native Flet web-render обеих тем.
Фактические Windows-аудио, DPI и screen reader требуют ручной приёмки.
Один отменяемый таймер закрытия, без новых постоянных задач/потоков/аудиозахвата.
