# Удаление WinRT из рабочего синтеза речи

## Изменения

- Из фабрики, auto-резерва, GUI и подсказок голосов убран WinRT TTS.
- Оставшийся порядок auto: **Silero → Piper → SAPI**.
- Старое `tts_backend=winrt` читается как `auto` с предупреждением.
  При самом чтении существующий config.json не переписывается; голос,
  скорость и остальные пользовательские параметры не удаляются.
- Старые engine/probe-кэши не могут вернуть удалённый движок.
- `jarvis/tts_engines/winrt.py` оставлен только как маркер удаления,
  выбрасывающий понятный ImportError. Это нужно для ZIP-обновления:
  распаковка должна заменить старую реализацию, а не оставить её на диске.
- Полная ручная AEC-диагностика — **Piper и Silero**. SAPI без PCM остаётся
  ограничен метаданными и явным предупреждением, без фиктивного эталона.

WinRT как Windows API не удаляется: `Media.Control` нужен для управления
системным медиаплеером. Не нужно вручную удалять все пакеты `winrt-*`.
Речевая SpeechSynthesis-зависимость убрана из runtime requirements;
уже установленные пакеты автоматически не деинсталлируются.

Независимый генератор тестовых WAV в tests/audio может по явному запуску
использовать системный синтезатор Windows, но он больше не импортирует
движок приложения и не умеет воспроизводить речь. Его SpeechSynthesis —
необязательная dev-зависимость. Это не скрытый резерв auto.

## Установка нового архива

Это объединённое обновление: предыдущие диагностические ZIP устанавливать
не нужно. Код содержит предыдущие исправления AEC и диагностику.

1. Полностью закрыть Феникс.
2. Распаковать этот архив в `C:\jarvis` с заменой и сохранением папок.
3. Для обычного использования запустить привычный `fenix`/`start_fenix.bat`.
4. Для диагностики выбрать Piper или Silero, оставить AEC включённым,
   затем перезапустить через `start_aec_diagnostics.bat` и подтвердить Y.
5. Попросить фразу, на которой возникает сбой, и молчать во время ответа.
   После сбоя дождаться `AEC diagnostic SAVED` и по своему решению отправить
   указанный ZIP. В нём есть микрофонная запись; автоматической отправки нет.

Подробности записи и её ограничения: `docs/AEC_LOCAL_DIAGNOSTICS.md`.
Пороги детектора этим удалением не повышаются. Для обычного запуска запись
по-прежнему выключена; лимиты ручного режима — прежние.
